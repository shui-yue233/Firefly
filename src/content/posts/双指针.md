# 三、单序列双指针

## §3.1 反转字符串

本质是相向双指针。

### [3823. 反转一个字符串里的字母后反转特殊字符](https://leetcode.cn/problems/reverse-letters-then-special-characters-in-a-string/)
说实话，这题解真看不懂，以后再说吧，但实际思路可以是先用两个string分别存放，然后reverse，最后再重新遍历s，按照对应字符替换就行

class Solution {
    void reverse(string& s, auto&& f) {
        int i = 0;
        int j = s.size() - 1;
        while (i < j) {
            while (i < j && f(s[i])) {
                i++;
            }
            while (i < j && f(s[j])) {
                j--;
            }
            swap(s[i], s[j]);
            i++;
            j--;
        }
    }

public:
    string reverseByType(string s) {
        reverse(s, ::islower);
        reverse(s, [](char ch) { return !islower(ch); });
        return s;
    }
};

也确实算到简单题，我还看条件一条一条判断，其实只要总结得出在for循环2k周期内，将前面k个反转就行了
i是+=2k哦
reverse(s.begin()+i,s.begin()+k+min(i+k,n));
min(i+k,n)是真的很妙，满足了剩余字符数少于k时全反转这一条件
