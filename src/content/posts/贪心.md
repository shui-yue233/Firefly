## 埃氏筛
	vector<bool> isPrime(n + 1, true);
	isPrime[0] = isPrime[1] = false;
	for (int i = 2; i * i <= n; i++) {
		if (isPrime[i]) {
			for (int j = i * i; j <= n; j += i) {
				isPrime[j] = false;
			}
		}
	}

对于小于n的所有质数的判断，我们通常是从2开始，遍历到n，然后对其中的每一个数都进行质数判断，这样我们的时间复杂度注定极大，对此，我们可以进行埃氏筛

首先，将所有的数都视作计数，对0和1直接不用判断就知道不是奇数，然后从2开始，我们判断奇数，如果是奇数，我们就可以将起始条件变为i的平方，之所以是i的平方而不是2i开始，是由于我们小于i的平方的数都已经被更小的质数标记过，所以直接i的平方能减少重复标记。
之后的每次递增i，是为了标记之后的每个倍数，然后将倍数标记为false即可。

## [954. 二倍数对数组](https://leetcode.cn/problems/array-of-doubled-pairs/)
主要的是哈希查表和数组遍历的思维，优先队列排小根堆
还有就是有负数的时候，多考虑一下是否要用偏移量变成正数
new PriorityQueue<>(<a,b>->Math.abs(a)-Math.abs(b))
此处的M是偏移量，足够将负数变为大于等于0
while(!q.isEmpty()){
	int x=q.poll(),t=2x;
	//这步实际上是在检查这个位置是否在之前就被预定过，即此时的x+M是之前的t+M
	if(cnt[x+M]!=0&&--cnt[x+M]>=0)continue;
	//这一步就是预定的过程
	cnt[t+M]++;
}
后面一个个检查cnt是否已经对应完毕，如果还有大于0的，就返回false

## [870. 优势洗牌](https://leetcode.cn/problems/advantage-shuffle/)
田忌赛马类的题目
我们用小的数去与大数配对
关于如何配对，我的想法是用map来记录相配对的数，但是有个问题是，如果需要比较的数组中有相同值的元素怎么办？
对此，ai说可以mutimap，这个我真没看过
还有方法就是，我们可以新建一个与需要比较的数组相同长度的下标数组
ranges::iota(数组名,0)    //从0开始填充数组
ranges::sort(数组名,{},lambda表达式}

lambda表达式:
[&]  :  指的是捕获所有元素，个人感觉就是抓住返回的值
(int i) ： 相当于函数里的形参
{函数体(例 : return nums2[i])}
